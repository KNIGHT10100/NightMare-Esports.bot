# Photos

Put your photos here. They are ignored by git on purpose, because this repository is public.

The page expects these five files (you can rename them, as long as `assets/js/config.js` matches):

| File | Shape | Shown as |
| --- | --- | --- |
| `us-adventure.jpg` | portrait, 3:4 | "partners in crime" |
| `phool-blossom.jpg` | portrait, 3:4 | "the prettiest phool" |
| `phool-monochrome.jpg` | portrait, 3:4 | "timeless" |
| `phool-sunshine.jpg` | portrait, 3:4 | "my sunshine" |
| `us-ropeway.jpg` | landscape, 16:10 (`wide: true` in the config) | "up in the clouds" |

Any photo works: it is cropped to fit its polaroid automatically. About 1000–1300 px on the long side
keeps the page quick on mobile data. Remove location data (EXIF) before sharing photos online.

A missing photo never breaks the page; its polaroid shows "photo coming soon" instead.
