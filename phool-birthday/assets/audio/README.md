# Your song

Save your song here as `song.mp3`. It loads as soon as the page opens and starts with her very first
tap (phones never allow sound before a tap). It pauses while the music box sings Happy Birthday at
the cake, then carries on from the same spot. Without the file, the page plays its own music-box
melody, so nothing breaks either way.

The file is ignored by git on purpose: a commercial recording must not be published in a public
repository. Add it only where you host the page for her (see the main README).
